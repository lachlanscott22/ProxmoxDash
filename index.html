Dashboard

PNG, SVG, WebP or JPEG up to 1 MB. Shown 34px tall in the header (wide logos are fine) and used as the browser tab icon. A transparent background looks best in both light and dark mode.

Notifications

Alerts are sent through Pushover. Add a destination for each app or group that should hear about it, then choose which alerts go where.

Pushover destinations

Each destination is an application token plus a user or group key from pushover.net. Tokens are stored on the cluster in /etc/pve/priv and are never sent back to the browser in full.
